# Security

## Secrets — Never Commit
- `DATABASE_URL`, `POSTGRES_PASSWORD`
- `JIRA_TOKEN`, `JIRA_EMAIL`
- `ANTHROPIC_API_KEY`
- `SLACK_BOT_TOKEN`, `SLACK_SIGNING_SECRET`

## Slack Bot Security
- Verify request signature on every incoming request
- Minimal scopes: `commands`, `chat:write`
- Never log tokens

## Input Validation
- TypeScript: Zod for API input validation
- Python: parameterized queries (`%s` placeholders, never f-strings)
- No `any` type in TypeScript

## Read-Only Mode Protection
- `NEXT_PUBLIC_READ_ONLY=true` blocks all mutations
- API returns 403 on POST/PUT/PATCH/DELETE
- UI hides edit/create/delete buttons
- Slack endpoints excluded from read-only

## Logging
- Log state changes and errors with context
- Never log: tokens, passwords, API keys, credentials
- Never send sensitive info via Slack webhooks
