# Testing

## Frontend (Jest + React Testing Library)

### Structure
- `src/__tests__/` — Unit tests
- `src/__tests__/integration/` — Integration tests (MSW mocking)

### Running
```bash
npm run test              # All tests
npm run test -- --watch  # Watch mode
npm run test:coverage    # Coverage report
```

### Example
```typescript
describe('RiskPanel', () => {
  it('should render risk title and severity badge', () => {
    render(<RiskPanel risk={mockRisk} />);
    expect(screen.getByText(mockRisk.title)).toBeInTheDocument();
    expect(screen.getByText('high')).toHaveClass('badge-danger');
  });
});
```

## Backend (pytest)

### Structure
- `tests/unit/` — No external deps
- `tests/integration/` — DB, API mocks

### Running
```bash
pytest                   # All tests
pytest tests/unit/       # Unit only
pytest -k "sync"         # By pattern
pytest --cov=scripts     # Coverage
```

### Example
```python
@patch('lib.jira_client.JiraClient.get_issue')
async def test_fetch_jira_issue(mock_get):
    mock_get.return_value = {'key': 'EUV-1234', 'summary': 'Test'}
    result = await fetch_issue('EUV-1234')
    assert result['key'] == 'EUV-1234'
```

## Coverage Targets
- Sync logic: 90%+
- API endpoints: 80%+
- Frontend components: 75%+
