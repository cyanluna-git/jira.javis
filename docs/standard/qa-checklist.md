## Test Suite

Run from the repo root:

```bash
bash scripts/test-standard-docs.sh
```

Or from `docs/standard/`:

```bash

```

The script prints `PASS:` / `FAIL:` / `SKIP:` per test and exits `0` if no
`FAIL` (a `SKIP` does not fail the run). `T6` (DOCX build), `T7`
(markdownlint), and `E4` (DOCX HTML-comment leak) are environmental and
will `SKIP` cleanly when their tools are absent.
