# Section Mapping — Eastbourne → PCAS Standard

This file enumerates every section in the two Eastbourne source documents and records
how each one is reflected (or intentionally not reflected) in the PCAS standard skeletons.

- **Source A (SDP):** `eastbourne.refer/Eastbourne Site Software Development Procedure (3).docx`
- **Source B (SCM):** `eastbourne.refer/Software Configuration Management Working Practice (2).docx`
- **Targets:** `pcas-sdp.md`, `pcas-scm.md`

## Status Vocabulary

The `Status` column uses one of the following four values only:

| Value                     | Meaning                                                                 |
| ------------------------- | ----------------------------------------------------------------------- |
| `planned`                 | Heading scaffolded in Phase 1, body to be authored in a later phase.    |
| `written`                 | Section body is already authored.                                       |
| `intentionally omitted`   | Section is deliberately not carried over to PCAS (rationale required). |
| `replaced`                | Section is superseded by a different PCAS structure (target required). |

## Numbering Notes

- Eastbourne SDP §1 contains a duplicate "1.1" — the second occurrence is the actual
  *Scope* sub-section. PCAS renumbers it to **§1.2** to make the hierarchy unambiguous.
- Eastbourne SCM §8.1 groups both Global and Local Eastbourne references under a single
  `8.1` parent. PCAS splits them into **§8.1 (Global)** and **§8.2 (Local Eastbourne)**
  to avoid two sibling headings sharing the `8.1` label. Original Eastbourne sub-numbers
  (§8.1.1 … §8.1.9) are preserved in the rightmost column for traceability.
