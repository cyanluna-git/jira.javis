# Javis Viewer

Next.js frontend for the Javis Jira/Confluence workspace.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Direct Write Setup

User-scoped Jira and Confluence write support now uses Atlassian OAuth 2.0 3LO.

Setup guide:

- [Atlassian direct write setup](/home/edwards/cyanluna.dev/jira.javis/docs/guides/javis-atlassian-direct-write-setup.md)

## Verification

```bash
npm run build
```
